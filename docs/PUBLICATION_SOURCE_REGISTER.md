# Publication-Only Source Register

Status date: 2026-08-25

These sources support research that is explicitly outside the approved thesis. They are retained here so language-model and prompt-sensitivity work can continue after thesis completion without leaking into the two-question thesis evidence base.

## Use Boundary

- Sources 1-3 support later external-system temporal-reasoning task design.
- Sources 4-5 support later prompt-sensitivity controls and scoring robustness.
- Sources 6-8 support later paired inferential analysis when a publication study has an adequate executed sample.
- None of these sources or proposed tests supplies evidence for either approved thesis research question.
